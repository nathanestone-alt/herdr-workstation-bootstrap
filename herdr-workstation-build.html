Build list

Arrival sequence

  • Keep the Windows Pro USB sealed and first check the MS-A2 under Settings → System → Activation.
  • Return the sealed USB if the machine already has activated Windows 11 Pro; use it to upgrade Home or install onto a blank system.
  • Use the existing monitor and Logitech receiver for initial setup, then move the HDMI connection to Comet.
  • Use the factory 2 TB SSD initially. Do not configure RAID or add the previously planned 4 TB SSD yet.

Recovery discipline

  • Use SSH or RDP over Tailscale normally; reserve Comet for boot failures, BIOS work and OS recovery.
  • Power the MS-A2, Comet and network equipment from battery-backed UPS outlets.
  • Create a Veeam recovery ISO, store it on Comet's 32 GB eMMC and boot-test it through virtual media.
  • Add the 20 TB backup drive in about one week; until then keep every important file in Git, on the laptop or in cloud storage.
